# Python

Phase 7 introduces the first useful Python API through pybind11.

Initial goals:

* Create games
* Create strategies
* Run simulations
* Collect results
* Configure experiments
* Access statistics

Python should provide a natural interface for experimentation rather than expose the entire C++ implementation.
